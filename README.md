# Website Profil Pribadi — Gwen Rengkung

Website profil pribadi yang responsif dan modern untuk **Gwen Rengkung** (asal Manado, Sulawesi Utara). Dirancang menggunakan perpaduan palet warna **Silver** dan **Brown** yang hangat dan elegan, serta dibangun dalam satu file HTML mandiri yang ringan dan mudah dipublikasikan.

---

## ✨ Fitur Utama

- **Desain Responsif (Mobile & Desktop):** Tampilan menyesuaikan secara otomatis pada layar smartphone, tablet, maupun desktop dengan menu navigasi mobile.
- **Tema Warna Silver & Brown:** Palet warna khusus berbasis *Silver* dan *Brown* yang lembut, bersih, dan estetis.
- **Profil & Biodata Lengkap:** Menampilkan perkenalan diri, informasi dasar (Tanggal Lahir, MBTI, Agama, Status Mahasiswa), serta lini masa **Riwayat Pendidikan**.
- **Minat & Hobi:** Kartu interaktif yang menyoroti minat di bidang *Fotografi & Estetika*, *Musik & Playlist*, serta *Jalan-Jalan & Alam*.
- **Muat Foto Profil Instan:** Mendukung pemuatan foto lokal (`image.png`) maupun pemilihan foto langsung dari galeri perangkat saat pratinjau.
- **Formulir Kontak & Bagikan Tautan:** Dilengkapi formulir pesan interaktif, tombol **Salin Tautan**, fitur **Bagikan Profil**, serta tombol **Unduh `index.html`** siap unggah.

---

## 🛠️ Teknologi yang Digunakan

- **HTML5** — Struktur semantik halaman web.
- **Tailwind CSS (CDN)** — Styling responsif dengan konfigurasi palet warna kustom (`silver` dan `brown`).
- **Google Fonts (Inter)** — Tipografi modern dan mudah dibaca.
- **Vanilla JavaScript** — Interaktivitas menu mobile, unggah pratinjau foto, validasi formulir pesan, notifikasi *toast*, dan fitur salin/unduh halaman.

---

## 📁 Struktur File

Pastikan file foto profil berada dalam satu folder yang sama dengan file HTML saat dijalankan secara lokal:

```text
profil-gwen-rengkung/
├── index.html          # File utama website (atau gwen-rengkung-profile.html)
├── image.png           # Foto profil utama
└── README.md           # Dokumentasi proyek
```

---

## 🚀 Cara Menjalankan secara Lokal

1. Simpan file HTML utama (`gwen-rengkung-profile.html` atau `index.html`) dan foto profil dengan nama **`image.png`** di dalam satu folder yang sama.
2. Klik dua kali file HTML tersebut untuk membukanya di browser (Chrome, Safari, Edge, atau Firefox).
3. Apabila foto belum muncul, klik bingkai foto atau tombol **"Pilih / Muat Foto Profil"** di halaman untuk memilih foto langsung dari perangkat Anda.

---

## 🌐 Cara Publikasi Online (Gratis)

Agar website profil dapat diakses siapa saja melalui tautan internet:

1. Buka website di browser dan muat foto profil Anda melalui tombol **"Pilih / Muat Foto Profil"** (jika belum terpasang).
2. Gulir ke bagian **Kontak & Tautan**, lalu klik tombol **"Unduh index.html"**.
3. Unggah file `index.html` tersebut ke salah satu layanan hosting gratis berikut:
   - **Netlify Drop:** Kunjungi [app.netlify.com/drop](https://app.netlify.com/drop), lalu seret dan lepas (*drag & drop*) file `index.html` ke area unggah.
   - **GitHub Pages:** Buat repositori baru di GitHub, unggah file `index.html` dan `image.png`, lalu aktifkan GitHub Pages melalui menu **Settings > Pages**.
4. Setelah aktif, tautan publik Anda otomatis siap dibagikan melalui tombol **"Salin Tautan"** di halaman.
